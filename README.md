## About this repository

This is a **static GitHub Pages site**, separate from the source of my main Vercel portfolio. It uses a restrained, terminal-inspired, accessible visual language, with project-specific demonstration pages for Chrome extensions.

```text
.
├── index.html              # Portfolio homepage
├── DESIGN.md               # Design tokens and UI conventions
├── clean-bookmarks/        # Product presentation
├── dash-reader/            # Product presentation
├── fetch-markdown/         # Product presentation
├── verify-redesign.mjs     # Structural checks for presentation pages
├── robots.txt
└── sitemap.xml
```

The site has **no dependency install, build step, or server-side runtime**. To preview locally:

```bash
python3 -m http.server 8000
# Open http://localhost:8000
```

To validate the current showcase structure (Node.js required):

```bash
node verify-redesign.mjs
```

Publishing occurs through GitHub Pages from this repository. For content updates, keep the homepage and this README consistent with the [main portfolio](https://shafiqimtiaz.vercel.app/); retain the project presentation URLs and follow [DESIGN.md](./DESIGN.md).
